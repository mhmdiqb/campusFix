# CampusFix

**CampusFix** adalah aplikasi pelaporan kerusakan fasilitas kampus yang membantu mahasiswa menyampaikan laporan dan membantu pihak kampus mengelola tindak lanjutnya.

🌐 **Demo aplikasi:** https://campus-fix-sable.vercel.app

## Fitur Utama

- Autentikasi pengguna dengan pembagian role.
- Pembuatan dan pengelolaan laporan kerusakan fasilitas.
- Informasi fasilitas dan kategori laporan.
- Penugasan laporan kepada teknisi.
- Pembaruan status laporan.

> Fitur dapat berubah seiring pengembangan proyek.

## Teknologi

### Frontend
- React
- Vite

### Backend
- Node.js
- Express.js
- Prisma ORM
- MySQL


## Menjalankan Proyek

Frontend dan backend dijalankan secara terpisah. Baca dokumentasi di folder masing-masing:

- [Frontend README](./frontend/README.md)
- [Backend README](./backend/README.md)

Secara umum, siapkan file environment sesuai konfigurasi lokal, pasang dependency, lalu jalankan server frontend dan backend.
